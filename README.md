# Проектная работа: «Сложно сосредоточиться»

Адаптивный одностраничный сайт, посвящённый теме концентрации внимания и борьбе с прокрастинацией. Проект выполнен в рамках курса веб-разработки Яндекс Практикума.

## О проекте

В проекте реализована адаптивная и «резиновая» вёрстка с поддержкой нескольких цветовых тем (тёмная тема «Неон», светлая тема «День» и автоматическая системная тема «Авто»). 

### Основные возможности:
* **Адаптивность (Mobile First):** интерфейс оптимизирован под мобильные устройства (375px), планшеты (768px) и десктопные экраны (1024px и выше).
* **Поддержка тем оформления:** переключение между светлой и тёмной темами вручную, а также автоматический выбор темы на основе системных настроек пользователя (`prefers-color-scheme`).
* **Сохранение состояния:** выбранная тема сохраняется в `localStorage` браузера.
* **Резиновая типографика:** плавное масштабирование заголовков с помощью функции `clamp()`.
* **Сетки Grid и Flexbox:** раскладка контента, шапки и галереи построена на современных возможностях CSS Grid.

##  Технологии

* **HTML5:** семантическая разметка (`<header>`, `<main>`, `<footer>`, `<section>`, `<article>`, `<nav>`), атрибуты доступности (`aria-hidden`).
* **CSS3:**
  * CSS Grid Layout и Flexbox
  * Кастомные CSS-переменные (`CSS Custom Properties`)
  * Медиавыражения (`@media`) с современным синтаксисом диапазонов
  * Медиафича `prefers-color-scheme`
  * Функция `clamp()` для адаптивного размера шрифтов
* **JavaScript:** переключение классов темы на корневом элементе и работа с `localStorage`.

## Структура проекта

* `index.html` — основная разметка страницы
* `styles/` — стили проекта:
  * `variables.css` — объявление CSS-переменных
  * `globals.css` — сброс базовых отступов и общие стили
  * `style.css` — основные стили страницы и медиазапросы
  * `dark.css` — переопределение переменных для тёмной темы
  * `light.css` — переопределение переменных для светлой темы
* `scripts/script.js` — скрипт управления темами
* `fonts/` — шрифты семейства IBM Plex Mono
* `images/` — изображения и фавиконки
